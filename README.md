# Gibbi Games

Little games, big fun. Home of the Gibbis.

- `index.html`: the Gibbi Games home page
- `gibbis/`: the Gibbis pet game (built from `tools/gibbis-source.html` with `python3 tools/build.py tools/gibbis-source.html`)
- `sw.js` + `*.webmanifest` + `icons/`: install-to-home-screen and offline support

Live at https://gibbi-games.github.io/Gibbi-Games/
